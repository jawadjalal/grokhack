# 05 · UI

**Owner:** Dhrishiv

One page. The judges see it on a projector for 3 minutes, so it has to be obvious from the back of the room.

## Paste this into your AI

> Read AGENTS.md and docs/05-ui.md. Polish app/page.tsx and app/globals.css only. Keep the layout (bottom composer, ranked table, drawer) and the design rules in AGENTS.md. Check it at 1280x720 for the projector.

## Build

`app/page.tsx`:

1. A single input: "Paste your event link" (and a fallback textarea to describe it).
2. Calls `/api/event`, then `/api/match`. Shows the event summary, then a ranked list of leads: name, score, 1-3 reasons, past backings as small links.
3. Click a lead: show its pitch (calls `/api/pitch` lazily), tier and price, with copy button.
4. "Push to Notion" button: calls `/api/push`, then shows the Notion links.
5. Loading states that say what's happening ("Finding who backed similar events…"), because the demo has waits.

## Design

Use the Ignaru design kit Jawad shares. Avoid: every item in identical bordered boxes, rows of bordered buttons, cream/peach/orange washes, small uppercase labels above headings, all-grey pages. Big type, real hierarchy, the score as the loudest thing on each row.

## Done when
